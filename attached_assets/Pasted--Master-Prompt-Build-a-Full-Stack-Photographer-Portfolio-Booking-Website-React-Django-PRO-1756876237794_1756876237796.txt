# Master Prompt: Build a Full-Stack Photographer Portfolio & Booking Website (React + Django) ## PROJECT GOAL
Design and develop a high-performance, mobile-first website for a professional photographer to showcase all information, photos, and videos; promote services (e.g., weddings, baby shower, haldi, mehndi, engagements, pre-wedding, maternity, newborn, family, corporate events); and convert visitors into bookings via an integrated contact/booking flow.

## AUDIENCE & BRAND
Target users: Couples, families, event planners, and brand managers in India.
Tone & vibe: Elegant, modern, artistic. Minimal UI with bold imagery. Premium yet friendly.
Brand elements: Photographer’s logo, brand colors (primary, secondary, accent), clean typography (e.g., Playfair Display + Inter).

## TECH STACK
Frontend: React (Vite or Next.js-style routing in React Router), TypeScript preferred, Tailwind CSS, Framer Motion for animations, React Query for data fetching, React Hook Form + Zod for forms.
UI components: Headless UI / Radix + custom components; lightbox (e.g., yet-another-react-lightbox) or custom; Masonry layout with CSS Grid.
Backend: Django 5 + Django REST Framework (DRF). Django Admin as CMS with custom ModelAdmin forms.
Storage: S3-compatible (AWS S3/MinIO) for images/videos via django-storages; local media for dev.
Database: PostgreSQL.
Auth: Django auth + JWT (djangorestframework-simplejwt) for admin/editor APIs.
Payments (optional but desirable): Razorpay integration for booking deposit.
Email/SMS/IM: Email via SMTP/SendGrid; WhatsApp CTA deep link; optional SMS via Twilio/MSG91.
Analytics: Google Analytics 4 + privacy-friendly alternative (Plausible/Umami).

## ADMIN (Django CMS) REQUIREMENTS
Secure Django Admin with custom ModelAdmins.
CRUD for: Categories, Tags, Photos, Albums (shoots), Videos, Services, Packages, Add-ons, Testimonials, Blog posts, FAQs, Lead submissions, Availability blocks, Venues.
Bulk upload images (drag & drop), auto-generate thumbnails, lossless compression, optional watermark toggle, alt text & captions required.
Reorder galleries via drag-and-drop ordering.
Video support: URL embeds + optional upload of short reels.
Publishing workflow: draft, scheduled publish, archive.
SEO fields per object: title, meta description, canonical, Open Graph, Twitter Card.
Slug generation with uniqueness; redirects for changed slugs.
Lead inbox with status (new, contacted, booked, closed) + notes.
Export leads to CSV.

## DATA MODEL (ILLUSTRATIVE)
Category: name, slug, description, cover_image
Tag: name, slug
Album (Shoot): title, slug, date, location, event_type (FK Category), description, hero_image, tags (M2M), is_featured, gallery (M2M Photo)
Photo: image, caption, alt_text, exif(json), taken_at, orientation, palette(json), is_featured, photographer_notes
Video: title, slug, thumbnail, url_or_file, provider(enum: youtube/vimeo/self), duration, categories, tags
Service: title, slug, description, base_price, deliverables(json)
Package: title, price, description, includes(json), add_ons(M2M AddOn)
AddOn: title, price, description
Testimonial: client_name, event_type, rating, body, date, location, photo(optional)
Lead: name, email, phone, city, event_type, event_date, budget_range, message, source, status, notes
AvailabilityBlock: start_date, end_date, status(enum: available/unavailable/hold)
BlogPost: title, slug, body, cover_image, published_at, tags

## API ENDPOINTS (DRF)
/api/v1/portfolio/photos?category=...&tag=...&page=...
/api/v1/portfolio/albums/:slug (includes photos & story)
/api/v1/videos?category=...&page=...
/api/v1/services /api/v1/packages
/api/v1/testimonials
/api/v1/leads (POST) → validates + sends email to studio + stores in DB
/api/v1/availability?month=YYYY-MM → dates blocked/available
/api/v1/seo/:slug → meta data for given route
/api/v1/upload (auth) → admin media upload
/api/v1/payment/razorpay/order (POST) & /payment/webhook (Razorpay webhook)

## FRONTEND UX & ANIMATIONS (Framer Motion)
Smooth page transitions (fade/slide), parallax hero, staggered grid reveals.
Hover micro-interactions on cards; magnetic buttons for CTAs.
Lightbox transitions with spring physics.
Reduced-motion setting respected via prefers-reduced-motion.
Skeleton loaders for gallery cards; optimistic UI for form submits.

## FORMS & CONVERSION
Contact/Booking form with strong validation (Zod), server-side validation fallback.
reCAPTCHA or hCaptcha. Honeypot field to reduce spam.
WhatsApp CTA: prefilled message text including event type/date.
On success: thank-you page + email confirmation to lead + notification to studio.
Optional: meeting scheduler link (Calendly) after form submit.

## PERFORMANCE & MEDIA
Image optimization: generate multiple sizes (thumb, card, hd, 4k); serve AVIF/WebP with fallback; lazy-load & priority hints for LCP image.
Video: use HLS/DASH for self-hosted; poster images; lazy-load embeds.
CDN for static & media; caching headers; HTTP/2 or HTTP/3; preconnect/preload critical assets.
Lighthouse targets: Perf ≥ 90, SEO ≥ 95, Accessibility ≥ 95, Best Practices ≥ 95.

## SEO & DISCOVERABILITY
Semantic HTML; correct heading structure.
Structured data (JSON-LD): Organization, LocalBusiness, Product (packages), Service, ImageObject, VideoObject, BreadcrumbList.
Dynamic meta titles/descriptions per page; Open Graph and Twitter Cards.
Clean readable URLs; sitemap.xml & robots.txt; canonical tags.
Blog for long-tail keywords; internal linking; venue/location pages (city-based landing pages for weddings, haldi, mehndi, baby shower, etc.).

## ACCESSIBILITY
WCAG 2.2 AA: alt text required, color contrast, focus states, skip links, keyboard navigation, ARIA labels, captions/transcripts for videos where applicable.

## SECURITY
HTTPS everywhere; CSRF protection for forms; rate limiting for /leads.
Validate all uploads (MIME/size/extension). Store secrets in env vars.
JWT expiry & refresh; Django Admin IP allowlist (optional).

## INTERNATIONALIZATION
English primary; optional Hindi switch (i18n-ready strings & content fields).

## DEVOPS & DELIVERY
Dockerized dev & prod; .env templates; Makefile or npm scripts.
CI/CD pipeline (GitLab/GitHub Actions): run tests, linting, type-checks, build, deploy.
Deploy targets: Render/Heroku/Fly.io for app; CloudFront/Cloudflare for CDN.
